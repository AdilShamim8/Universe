# Rights policy

- Publicly readable ≠ redistributable. Unknown rights = link-only or no import.
- Per-record rights modes: link-only, metadata-only, permitted-redistribution, restricted, prohibited.
- Crossref: bibliographic metadata only; abstracts excluded (ADR 0005).
- OpenStax Astronomy 2e: link-only reading recommendation; its CC BY-NC-SA terms and AI-use restrictions forbid ingestion into model workflows.
- NASA media: educational-use permission varies per asset; third-party content inside NASA pages has separate restrictions; NASA identifiers/branding must not imply endorsement.
- UAT taxonomy: CC BY-SA 3.0 — referenced, not vendored; any future derived taxonomy must carry compatible share-alike licensing and attribution.
- Visualization code references (OpenSpace, WWT engine): code licenses are not data licenses; no wholesale copying.
- Proposed project defaults (pending owner ratification): Apache-2.0 for original code, CC BY 4.0 for original human-authored content.
