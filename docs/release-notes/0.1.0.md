# 0.1.0 — Engineering preview (2026-11-17)

First engineering release. **Contains zero approved scientific records by design**: no
reviewers are registered yet, so every public section renders an honest empty state.

## What works
- Contracts: 14 versioned JSON Schemas + TS types + Ajv validation.
- Registry: deterministic discovery, reference/type integrity, module DAG +
  lesson prerequisite cycle rejection, review-hash verification, decimal-safe
  4-frame temporal model, fail-closed approved projection.
- Compiler: nav/coverage/level/redirect site data (deterministic).
- UI: tokens, base CSS, accessible no-JS components.
- Visualizations: timeline engine (log zero-safe/linear/schematic, interval
  bars, unknown-time honesty, keyboard model) + SVG/list renderers — fixture demo only.
- Web: 13-page static Astro site, preview banner, dark/light themes,
  reduced-motion support, 320px-safe, fixture demo noindex/search-excluded.
- Search: Pagefind with verified fixture exclusion.
- Ingestion: Crossref metadata-only adapter, SSRF-safe fetcher, dry-run CLI.
- Tools: validation CLI, immutable release manifest generator.
- CI: full gate pipeline with pinned action SHAs; weekly dry-run scan; release workflow.

## What deliberately does not exist yet
- Registered reviewers, approved content, public deployment, cleared name,
  ratified licenses. See ADRs 0002/0006 and docs/editorial.
